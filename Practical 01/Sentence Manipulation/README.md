# Question 03 – Sentence Manipulation

## Description
This Java program accepts a sentence from the user and performs different string manipulation operations.

## Requirements
- Accept a sentence from the user.
- Count and display the number of words in the sentence.
- Find and display the longest word.
- Reverse the input sentence and display the reversed sentence.

## Concepts Practiced
- Strings
- String manipulation
- StringBuilder
- Scanner class
- Loops
- Arrays and string methods

## Technologies Used
- Java
- IntelliJ IDEA
