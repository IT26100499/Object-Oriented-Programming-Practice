# Question 05 – Word Array Operations

## Description
This Java program accepts five words from the user and stores them in a String array. It performs operations to identify the longest word, calculate the total number of characters, and find words containing an even number of characters.

## Requirements
- Accept five words from the user.
- Store the words in a String array.
- Find and display the longest word.
- Calculate and display the total number of characters in all five words.
- Identify and display words containing an even number of characters.

## Concepts Practiced
- String arrays
- Scanner class
- Loops
- String length() method
- Conditional statements
- String manipulation

## Technologies Used
- Java
- IntelliJ IDEA
