# Question 01 – Employee Salary Calculator

## Description
This Java program calculates an employee's total salary based on their employment type, basic salary, and overtime hours.

## Requirements
- Accept employee type (1, 2, or 3).
- Accept basic salary.
- Accept overtime hours.
- Assign the overtime rate according to the employee type.
- Calculate and display the total salary including overtime pay.

## Overtime Rates

| Employee Type | Overtime Rate |
|---|---:|
| Type 1 | 1000 |
| Type 2 | 1500 |
| Type 3 | 1700 |

## Formula
Total Salary = Basic Salary + (Overtime Hours × Overtime Rate)
