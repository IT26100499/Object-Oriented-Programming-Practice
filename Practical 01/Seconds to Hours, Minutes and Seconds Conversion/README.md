# Question 04 – Time Conversion

## Description
This Java program converts a given number of seconds into hours, minutes, and remaining seconds.

## Requirements
- Accept an integer number of seconds from the user.
- Convert the total seconds into hours.
- Convert the total seconds minutes.
- Calculate the remaining seconds.
- Display the converted time.

## Example
Input: 3645 seconds

Output:
- Hours: 1
- Minutes: 60
- Seconds: 45

## Concepts Practiced
- Scanner class
- Integer variables
- Arithmetic operations
- Division operator (/)
- Modulus operator (%)

## Technologies Used
- Java
- IntelliJ IDEA
