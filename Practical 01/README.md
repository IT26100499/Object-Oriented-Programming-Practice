# Practical 01 – Java Programming Fundamentals

## Description
This practical contains five Java programming exercises completed as part of the university Object-Oriented Programming (OOP) practical sessions.

The exercises focus on basic Java programming concepts, user input, arrays, strings, arithmetic operations, and problem-solving techniques.

## Questions

| Question | Topic |
|---|---|
| Question 01 | Employee Salary Calculation |
| Question 02 | Array Operations – Largest Value and Sum |
| Question 03 | Sentence Manipulation |
| Question 04 | Seconds to Hours, Minutes and Seconds Conversion |
| Question 05 | Word Array Operations |

## Concepts Practiced
- Variables and data types
- User input using Scanner
- Conditional statements and switch statements
- Arrays
- Loops
- Arithmetic and modulus operators

## Technologies Used
- Java
- IntelliJ IDEA

## Purpose
These practical exercises were completed to develop Java programming skills, understand fundamental programming concepts, and improve logical thinking and problem-solving abilities.
