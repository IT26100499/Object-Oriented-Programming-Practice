# Question 02 – Array Operations

## Description
This Java program accepts five integer values from the user and stores them in an array. It then finds the largest value and calculates the sum of all elements.

## Requirements
- Accept five integer values from the user.
- Store the values in an integer array.
- Find the largest value in the array.
- Calculate the sum of all array elements.
- Display the largest value and the total sum.

## Concepts Practiced
- Arrays
- Scanner class
- For loops
- Conditional statements
- Arithmetic operations

## Technologies Used
- Java
- IntelliJ IDEA
