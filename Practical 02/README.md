# Practical 02 – Object-Oriented Programming

## Overview
This focuses on implementing Object-Oriented Programming (OOP) concepts in Java. It covers classes, objects, encapsulation, getters, setters, data validation, and methods.

## Questions

### Question 01 – Savings Account Management
Developed a `SavingsAccount` class to manage customer savings accounts. Implemented encapsulation to protect the account balance and methods to deposit and withdraw money while maintaining a non-negative balance.

### Question 02 – Product Management System
Created a `Product` class to manage retail store products. Implemented getters, setters, validation, product detail display, and stock value calculation.

### Question 03 – Employee Performance and Bonus Management
Designed an employee management system to calculate performance-based bonuses and total salaries according to the employee's performance rating.

## Concepts Covered
- Classes and Objects
- Encapsulation
- Private Attributes
- Getters and Setters
- Data Validation
- Methods
- Conditional Statements
- Basic Calculations
