# Employee Salary Calculator

## Description
This Java program calculates an employee's total salary based on their employment type, basic salary, and overtime hours.

This program was developed as part of university Object-Oriented Programming (OOP) practical exercises.

## Features
- Accepts employee type (1, 2, or 3).
- Accepts basic salary.
- Accepts overtime hours.
- Assigns overtime rates based on employee type.
- Calculates total salary including overtime payment.
- Displays the employee's total salary.

## Overtime Rates

| Employee Type | Overtime Rate |
|---|---:|
| Type 1 | 1000 |
| Type 2 | 1500 |
| Type 3 | 1700 |

## Salary Calculation

Total Salary = Basic Salary + (Overtime Hours × Overtime Rate)
